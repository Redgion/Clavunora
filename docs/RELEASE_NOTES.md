Clavunora — новое имя PianoFlow. Это офлайн-тренажёр фортепиано с оформлением Frutiger Aero.

- 98 доступных произведений, пять уровней сложности и курс с нуля. Два исходных названия сохранены в плане, но их редакции временно не распространяются.
- Падающие ноты, ожидание нажатий, изменение скорости, фрагменты, статистика, MIDI-импорт и запись.
- Разметка рук и пальцев зависит от произведения; MIDI не определяет используемый палец.

Linux: используйте `.rpm` для Fedora или `.deb` для Ubuntu 24.04+ — откройте пакет в системном установщике. Для переносимой установки распакуйте архив и запустите `Clavunora/install.sh` (из терминала: `sh install.sh`). Установка выполняется без sudo в личную папку, ярлык появится в меню. Также можно запустить `Clavunora` прямо из распакованной папки. Нужен совместимый Linux x86_64 с glibc 2.39 или новее.

Windows: запустите `Clavunora-…-windows-x64-setup.exe`. Есть также переносимый ZIP. Установщик пока без цифровой подписи издателя.

В библиотеке есть материалы CC BY-NC-SA: комплект предназначен для некоммерческого использования. Исходники нот, авторство и лицензии находятся в каталоге ресурсов приложения. Пользовательская библиотека и результаты хранятся отдельно от установленной программы.

Android — экспериментальная ARM64-версия для Android 9+, с компоновкой для телефонов/планшетов и экранной клавиатурой. Подключение внешнего инструмента по USB/Bluetooth MIDI пока недоступно. Проверка на реальном устройстве ещё требуется; APK публикуется как предварительная версия.

При обновлении сохраняются библиотека и прогресс. Android использует прежний идентификатор приложения и ключ подписи, Windows — прежний идентификатор установщика; Linux-пакет заменяет предыдущий пакет PianoFlow.
