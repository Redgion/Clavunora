# Android: предварительная версия

Телефоны и планшеты ARM64, Android 9 (API 28) или новее. Меню разделов заменяет боковую панель на узком экране; папки библиотеки располагаются над списком. Кнопки переносятся, настройки урока прокручиваются отдельно, запуск и остановка остаются доступны. На телефоне показывается октава с кнопками переключения. Работают несколько касаний; при сворачивании практика останавливается.

Это первая экспериментальная Android-сборка. USB/Bluetooth MIDI через Android MidiManager пока не реализован: играйте на экранной клавиатуре. Реальный телефон/планшет, звук и системный выбор документов требуют проверки на устройстве; настольная проверка размеров окна не заменяет её. Файлы из Android document provider читаются и записываются через Qt QFile.

## Сборка

Нужны Linux, Python 3.12, JDK 17, Android SDK API 35 и NDK r28c (28.2.13676358). CI устанавливает эти инструменты. Используются официальные Android-колёса Qt/PySide6 6.12.0 и Shiboken; SHA-256 проверяется до сборки. Версия python-for-android закреплена официальным генератором Qt; не меняйте её отдельно от Android-колёс.

```sh
python -m pip install PySide6==6.12.0 mido packaging jinja2 pkginfo tqdm buildozer==1.6.0
python scripts/build_android.py --sdk /path/to/sdk --ndk /path/to/ndk
```

Скрипт создаёт чистое дерево `build/android-package`, генерирует рецепты Qt, добавляет sqlite3 и расширения нотных ресурсов, затем собирает release APK. При повторной подготовке после изменений используйте новую папку `--stage`, чтобы не собрать старые исходники.

Сборка выдаёт `dist/Clavunora-…-android-arm64-unsigned.apk`. Этот промежуточный файл нельзя устанавливать или публиковать как готовую версию. Подпись выполняется локально:

```sh
python scripts/sign_android.py dist/Clavunora-…-android-arm64-unsigned.apk \
  --jdk /path/to/jdk17 --build-tools /path/to/sdk/build-tools/35.0.0
```

Закрытый ключ и пароль создаются в `build/release-signing` и исключены из Git. Сохраните резервную копию этой папки в защищённом месте: для обновлений установленного APK нужен тот же ключ. В GitHub Release размещается только итоговый подписанный APK. Подпись не означает, что приложение проверено Google Play.

Документация Qt: https://doc.qt.io/qtforpython-6/deployment/deployment-pyside6-android-deploy.html
